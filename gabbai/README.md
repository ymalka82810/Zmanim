# קופת בית הכנסת – אפליקציית גבאי

אפליקציה לניהול כספי בית הכנסת. היא עוקבת אחרי תרומות, מכירת מצוות, משכורת, הוצאות וקופה קטנה. כל תאריך מוצג כתאריך לועזי, כתאריך עברי ועם פרשת השבוע.

## מבנה הקבצים
- `index.html` – מבנה הדף, הטפסים והחלונות.
- `css/styles.css` – העיצוב. הצבעים מוגדרים כמשתנים ב-`:root`, ויש תמיכה במצב כהה.
- `js/app.js` – כל הלוגיקה: הנתונים, החישובים, התצוגות והייצוא.
- `../vendor/hebcal/hebcal-core-6.9.3.min.js` – ספריית Hebcal (משותפת עם לוח הקידושים) לחישוב התאריך העברי ופרשת השבוע. רישיון GPLv2.

## הפעלה
האפליקציה היא חלק מאתר לוח הזמנים, בכתובת `gabbai/`. מתיקיית האתר הראשית: `npm start`, ואז http://localhost:8080/gabbai/

## שמירת נתונים
- בתוך claude.ai הנתונים נשמרים במסד הנתונים של הארטיפקט (`claude.use("db")`).
- מחוץ ל-claude.ai הנתונים נשמרים ב-localStorage, תחת המפתח `gabbai-fallback-v1`, בדפדפן הנוכחי בלבד.

כל הגישה לאחסון מרוכזת בפונקציות `putTx`, `delTx` ו-`putSettings` בקובץ `app.js`. כדי לחבר את האפליקציה לשרת או למסד נתונים של הפרויקט המאוחד, מספיק להחליף את הפונקציות האלה ואת קטע ה-boot שבסוף הקובץ.

## מודל הנתונים
כל רשומה היא אובייקט אחד:

| שדה | משמעות |
|---|---|
| `type` | `donation` / `mitzvah` / `salary` / `expense` / `petty` / `pettyIn` |
| `amount` | סכום בש"ח |
| `date` | תאריך ב-ISO (YYYY-MM-DD) |
| `name` | שם התורם או הקונה (בתרומה ובמצווה) |
| `mitzvah` | שם המצווה (במצווה) |
| `month` | החודש שעבורו המשכורת (במשכורת) |
| `category`, `vendor` | קטגוריה וספק (בהוצאה ובקופה קטנה) |
| `desc` | תיאור או הערה |
| `method` | אמצעי תשלום |
| `paid`, `paidDate` | האם שולם ומתי (בהכנסות) |
| `createdAt` | חותמת זמן, לשמירת סדר הרשומות |

ההגדרות נשמרות באובייקט `{synName, openMain, openPetty, israel}`.

## כללי החשבונאות
- **עו"ש:** הכנסות נרשמות רק כשהן מסומנות כשולמו, לפי `paidDate`. הוצאות ומילוי קופה קטנה נרשמים בחובה.
- **קופה קטנה:** מילוי הקופה נרשם בזכות, וקנייה מהקופה נרשמת בחובה.
