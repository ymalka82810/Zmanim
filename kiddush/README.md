# לוח קידושים לבית כנסת

מערכת לניהול הרשמה לקידושים בשבתות ובחגים. בנויה כתשתית גנרית שתומכת בכמה בתי כנסת.

גרסה חיה: https://claude.ai/artifact/6YxdWTcYoYyNqDMQN4wZGh

המערכת היא חלק מאתר לוח הזמנים, בכתובת `kiddush/`.

## מבנה התיקייה

| קובץ | תפקיד |
|---|---|
| `index.html` | שלד העמוד, טוען את כל הקבצים |
| `css/styles.css` | עיצוב, ערכי צבע לבהיר וכהה, RTL |
| `js/calendar.js` | חישוב שבתות, פרשות וחגים לפי מיקום (א״י / חו״ל). חושף `window.KiddushCalendar` |
| `js/default-terms.js` | הנחיות ברירת מחדל שנוצרות בהקמת בית כנסת חדש |
| `js/local-store.js` | מאגר נתונים מקומי (localStorage) כשאין `window.claude` |
| `js/app.js` | מצב האפליקציה, מסכים, פעולות וכתיבה למאגר |
| `docs/data-model.md` | מבנה הנתונים המלא |
| `docs/integration.md` | איך לחבר לפרויקט אחר |

## תלויות

- `@hebcal/core@6.9.3` מ-`../vendor/hebcal/` (לוח עברי, פרשות, חגים)
- גופנים: Frank Ruhl Libre, Assistant (Google Fonts)
- מאגר נתונים: `window.claude.use("db")` של Claude Artifacts. מחוץ ל-Claude, `js/local-store.js` מספק את אותו ממשק ושומר ב-localStorage של הדפדפן, עם משתמש אחד שהוא בעל המערכת. הממשק שלו דומה ל-Firestore, כך שקל להחליף (ראו `docs/integration.md`).

## הרצה מקומית

מתיקיית האתר הראשית: `npm start`, ואז http://localhost:8080/kiddush/

מחוץ ל-Claude הנתונים נשמרים רק בדפדפן הנוכחי. כדי שכמה מתפללים ישתפו לוח אחד צריך לחבר מסד נתונים משותף (ראו `docs/integration.md`).

## תפקידים

- **מתפלל**: צפייה בלוח, הרשמה, ביטול, "הקידושים שלי"
- **אחראי קידושים**: בנוסף, אישור/דחייה, רישום ידני, חסימת תאריכים
- **הנהלה**: בנוסף, ניהול חברים ותפקידים, עריכת הנחיות עם היסטוריית גרסאות, פרטי בית הכנסת
- **בעלים (owner)**: הקמת בתי כנסת חדשים
