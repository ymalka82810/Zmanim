# רשימת משאלות

רעיונות לעתיד שעוד לא נכנסו לעבודה.

## דחיפות גבוהה: פיצ'רים שלא עובדים באפליקציית ה-APK

הדפסת לוח הזמנים והורדות הקבצים (גיבוי הגדרות, CSV של הגבאי, .ics, וה-fallback של שיתוף תמונה/PDF) עוברים עכשיו דרך `js/native-files.js` ותוסף native מקומי (`android/.../NativeFilesPlugin.java`: PrintManager, שמירה לתיקיית ההורדות דרך MediaStore, פתיחת .ics ביומן). נשאר: לבנות APK ולבדוק בפועל במכשיר (כולל אנדרואיד 9 ומטה, שבו במקום שמירה נפתח חלון שיתוף).

גם כפתור "חזרה" של אנדרואיד (`SiteBack` ב-`js/menu.js` + `MainActivity.java`) וקישורי הזמנה/יומן שהצביעו על `https://localhost` (`SiteAuth.publicUrl` ב-`js/auth.js`) תוקנו, ומחכים לבדיקה ב-APK.

### בדיקות לעשות ב-APK

קוד ה-Java לא קומפל (אין JDK במחשב הפיתוח), ולכן קודם כל: `npm run app:sync`, בנייה ב-Android Studio (`npm run app:open`) ותיקון שגיאות קומפילציה אם יש, ב-`NativeFilesPlugin.java` וב-`MainActivity.java`.

**הדפסה** (לוח זמנים ← "הדפסה"):
- [ ] נפתח חלון ההדפסה של אנדרואיד, ובתצוגה המקדימה רואים את הלוח בלבד (בלי תפריט וכפתורים), כמו בהדפסה מהמחשב.
- [ ] גודל הדף וכיוונו לפי התבנית: לבדוק תבנית A4 לאורך ותבנית A3 או לרוחב.
- [ ] לוח שנדחס לעמוד אחד פחות במחשב (עד חצי עמוד בעמוד האחרון) נדחס גם כאן, ואין עמוד ריק בסוף.
- [ ] לוח בעיצוב מקובץ (תמונה) ולוח בעמודות מודפסים נכון.
- [ ] "שמירה כ-PDF" מחלון ההדפסה יוצרת קובץ תקין.
- [ ] אחרי סגירת החלון (גם בביטול) הלוח במסך חוזר לתצוגה הרגילה.

**הורדות קבצים** (בכל אחת: הודעה "נשמר בהורדות", והקובץ מופיע באפליקציית הקבצים תחת Downloads עם השם הנכון, ונפתח):
- [ ] הגדרות ← גיבוי ← שמירת קובץ ההגדרות (.json). אחר כך לבדוק שיבוא של אותו קובץ עובד.
- [ ] קופה (גבאי) ← ייצוא דוח עו"ש ודוח קופה קטנה (.csv): נפתח באקסל/Sheets והעברית תקינה.
- [ ] לוח קידושים ← הוספה ליומן ← Apple: קובץ ה-.ics נפתח ישירות באפליקציית היומן עם התאריך הנכון והתזכורות.
- [ ] שמירה פעמיים של אותו קובץ לא נכשלת (אנדרואיד מוסיף מספר לשם).
- [ ] באנדרואיד 9 ומטה (אם יש מכשיר או אמולטור): במקום שמירה נפתח חלון שיתוף, ואפשר לשמור או לשלוח משם.

**כפתור "חזרה"**:
- [ ] תפריט ההמבורגר פתוח ← "חזרה" סוגר אותו.
- [ ] מגירה פתוחה בלוח קידושים / יומן קהילה / החשבון שלי ← "חזרה" סוגר אותה.
- [ ] חלון פתוח בקופה (תנועה, חיוב, הגדרות) ← "חזרה" סוגר אותו בלי לשמור.
- [ ] הודעת אישור של האתר (למשל לפני מחיקה) ← "חזרה" נחשב "ביטול" ולא מוחק.
- [ ] לוח זמנים: מההגדרות ← חוזר ללוח; מעורך התבנית ← שואל אם לבטל את העיצוב.
- [ ] מעבר בין דפים בתפריט ← "חזרה" חוזר לדף הקודם.
- [ ] בדף הראשון, בלי שום דבר פתוח ← האפליקציה עוברת לרקע, ובחזרה אליה היא באותו מצב.
- [ ] אחרי התחברות עם Google, "חזרה" לא מחזיר לדף ההתחברות ולא נתקע.

**קישורים ציבוריים**:
- [ ] החשבון שלי ← קהילה ← העתקת קישור הזמנה: הקישור מתחיל ב-`https://ymalka82810.github.io/Zmanim/account/?join=` ונפתח במכשיר אחר.
- [ ] הוספה ליומן Google/Outlook מלוח הקידושים: הקישור בתיאור האירוע מצביע על האתר הציבורי ולא על localhost.

**שיתוף** (`NativeFiles.share` ב-`js/native-files.js`, פעולת `share` ו-`shareText` ב-`NativeFilesPlugin.java`):
- [ ] לוח זמנים ← שיתוף תמונה / שיתוף PDF: נפתח חלון השיתוף של אנדרואיד, ושליחה בוואטסאפ מגיעה עם קובץ תקין.
- [ ] החשבון שלי ← קהילה ← "שיתוף" קישור ההזמנה: נפתח חלון שיתוף עם הקישור (ולא רק העתקה).

**בחירת קבצים**:
- [ ] בעורך התבנית ← העלאת קובץ גופן: קובצי ttf/otf מופיעים לבחירה (באפליקייה ה-`accept` מוסר לפני הפתיחה, ב-`js/template-ui.js`), וקובץ שאינו גופן מקבל הודעת שגיאה.
- [ ] בחירת קובץ תבנית (PDF/תמונה) ויבוא גיבוי (json) עובדים.

**מיקום** (ערכת נושא "אוטומטי", `js/theme.js`; נוספו ב-`AndroidManifest.xml` ‏`ACCESS_COARSE_LOCATION`, ו-`ACCESS_FINE_LOCATION` עד אנדרואיד 11 בלבד):
- [ ] "אוטומטי" היא ברירת המחדל, ולכן הרשאת המיקום נשאלת כבר בפתיחה הראשונה של האפליקייה. אחרי אישור ואחרי אישור (גם "משוער" באנדרואיד 12 ומעלה) המעבר לכהה/בהיר לפי המיקום.
- [ ] בדחייה – אין שגיאה, ונשארים עם העיר מההגדרות.

- **תשלום חיצוני לתרומות**: חיבור לספק תשלומים, כדי שחבר קהילה יוכל לתרום ישירות מהאפליקציה והתרומה תירשם בקופה אוטומטית.
- **דוח/סיכום חודשי אוטומטי לקופה**: יש כבר cron יומי לתזכורות תשלום (`convex/crons.ts` → `fund.sendDueReminders`). אפשר להוסיף לו cron חודשי נוסף ששולח לגבאי/רב סיכום הכנסות/הוצאות וחיובים פתוחים.
- **התראות מייל/פוש למנהלים על בקשות ממתינות**: קידוש/קופה כבר יוצרים התראות בתוך האפליקציה (`convex/notifications.ts`, טבלת `notifications` עם `type` "kiddush"/"fund"), אבל גבאי שלא פותח את האתר מפספס בקשות. כדאי להרחיב את מנגנון שליחת המייל שכבר קיים להזמנות (`convex/email.ts`) כך שישמש גם לקידוש/קופה/אישור אירועי קהילה, ולא רק להזמנות.

## מיילים (`convex/email.ts`): נשאר לסגור

- **דומיין לא מאומת ב-Resend**: `RESEND_API_KEY` כבר מוגדר בסביבת הפיתוח, אבל בלי דומיין מאומת ב-Resend המייל יוצא מ-`onboarding@resend.dev` ומגיע רק לבעל חשבון ה-Resend (מצב בדיקה) — הזמנות אמיתיות לחברי קהילה אחרים לא מגיעות. לפי ההחלטה של יניב: להמשיך לבדוק עם עצמו בלבד, ו**לכבות/לנתק את שליחת המייל** לפני שמשתמשים אמיתיים יסתמכו עליה, עד שדומיין ייקנה ויאומת.
- **פריסה ל-production**: יש להריץ `npx convex deploy` ולהגדיר שם את אותם משתני סביבה (`RESEND_API_KEY`, `RESEND_FROM_EMAIL`, `SITE_URL`, `AUTH_GOOGLE_ID/SECRET`, `OWNER_EMAIL`) לפני שהאתר החי (GitHub Pages) מסתמך על deployment נפרד מזה של הפיתוח.
- **תלות ב-`SITE_URL`**: הקישור במייל נבנה מ-`SITE_URL` ועוד `/Zmanim/account/`. אם המשתנה חסר או שכתובת האתר משתנה, הקישור שבור. עדיף משתנה אחד עם הכתובת המלאה של דף החשבון.

## מומש בינתיים (לא לחזור עליו)

לתיעוד — כדי שלא יוצע שוב כרעיון חדש: תפקיד רב, הזמנות במייל עם מעקב סטטוס שליחה, לוח קידושים וקופה ולוח זמנים תחת קהילות ב-Convex (roles/memberships/kiddush/fund/schedules), לוח שנה קהילתי משותף ואירועי קהילה בטקסט חופשי, והגדרות לוח הזמנים (`js/config.js`) שעברו מ-localStorage בלבד לסנכרון לפי קהילה ב-Convex (`convex/zmanimSettings.ts`, `js/settings-sync.js`), ואיחוד מנגנון ההתראות של קידוש וקופה לטבלה/מודול משותף (`convex/notifications.ts`). פירוט בזיכרון `project_communities_roadmap`.

## רעיונות לייעול המערכת

- **הפקת `sw.js` אוטומטית**: רשימת הקבצים (`SHELL`) ומספר הגרסה (`CACHE = 'luach-vNN'`) מתעדכנים ידנית בכל שינוי — קל לשכוח קובץ חדש או לשכוח להעלות מספר גרסה, מה שגורם לגרסה ישנה להישאר תקועה במטמון אצל משתמשים. סקריפט build קטן שסורק את התיקיות וכותב את `sw.js` (עם hash של התוכן במקום מספר ידני) יבטל את הסיכון הזה.
- **בדיקות אוטומטיות ב-CI**: יש כבר תשתית בדיקות ב-Node עם `window`/`fetch` מדומים (כמו ב-`kiddush/`), אבל לפי מה שנראה הן רצות ידנית. עם כמות הלוגיקה שנוספה (זיהוי תאריכים מלוח ישן, OCR, השלמת גופנים עבריים חסרים, חוקי לוח) שווה להריץ את הבדיקות אוטומטית ב-GitHub Actions על כל push, כדי לתפוס רגרסיות בפיצ'רים ישנים כשמוסיפים חדשים.
- **לוג שגיאות גלוי לבעלים**: היום שגיאות של actions ב-Convex (שליחת מייל, cron) נרשמות רק ב-console.error וזמינות רק בלוח הבקרה של Convex. אפשר להרחיב את התבנית שכבר קיימת למעקב סטטוס הזמנות (`setEmailStatus`) לטבלת לוג כללית, כדי שבעל האתר יראה כשלים (מייל, cron) בתוך דף "החשבון שלי" ולא רק ב-Convex dashboard.
- **ניקוי/ארכוב נתונים ישנים**: קידוש וקופה צוברים רשומות לאורך שנים בלי מנגנון ארכוב — כדאי לתכנן מראש (למשל תיוג לפי שנה עברית) כדי שרשימות וטעינות לא יאטו ככל שהקהילה צוברת היסטוריה.
