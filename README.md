# לוח זמנים לבית הכנסת

אפליקציה שמחשבת את זמני התפילות לשבתות ולחגים לפי כללים שמגדירים בטופס (למשל "מנחה 40 דקות לפני השקיעה, מעוגל ל-5"), מפיקה לוח PDF ושולחת אותו למייל לפני כל שבת וחג.

רצה כ-Google Apps Script, בחינם, ושולחת מחשבון ה-Gmail של מי שמתקין אותה.

## מה יש בפנים

- `Code.gs` – כל הקוד: חישוב הזמנים, בניית ה-PDF, שליחת המייל והטופס (Web App).
- `appsscript.json` – הגדרות הפרויקט (אזור זמן, הרשאות ה-Web App).

## התקנה

1. נכנסים ל-[script.google.com](https://script.google.com) ויוצרים פרויקט חדש.
2. מדביקים את התוכן של `Code.gs` ושומרים.
3. פריסה ← פריסה חדשה ← סוג: **אפליקציית אינטרנט**.
   ביצוע בתור: **אני**. גישה: **רק אני**.
4. מאשרים את ההרשאות ופותחים את הקישור שמתקבל.
5. בטופס: ממלאים את פרטי בית הכנסת והתפילות, לוחצים **שמירה**, בודקים עם **שליחה עכשיו**, ומפעילים את **השליחה האוטומטית**.

אחרי שינוי בקוד צריך לעדכן את הפריסה: פריסה ← ניהול פריסות ← עריכה ← גרסה חדשה.

### סנכרון מהריפו עם clasp (אופציונלי)

```bash
npm install -g @google/clasp
clasp login
clasp clone <SCRIPT_ID>   # או: clasp create --type webapp --title "לוח זמנים"
clasp push
```
