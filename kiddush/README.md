# לוח קידושים לבית כנסת

לוח שבתות וחגים שמציג מי נותן קידוש בכל שבת. הנתונים נמצאים בגיליון גוגל של בית הכנסת:
המתפללים נרשמים בטופס שבלוח, הרישום נכתב בגיליון, והלוח מסדר את הרישומים לפי חודש עברי או לועזי.

המערכת היא חלק מאתר לוח הזמנים, בכתובת `kiddush/`.

## איך זה עובד

1. **הגבאי מקים גיליון.** בעמוד הפתיחה של הלוח הוא ממלא את שם בית הכנסת ואת המיקום ולוחץ "יצירת הגיליון בגוגל".
   הגיליון נוצר בדרייב של הגבאי, עם שורה לכל שבת וחג בשנה הקרובה. הוא משותף רק עם שומר הסף, כך שהמתפללים לא יכולים לערוך בו.
2. **הגבאי שולח למתפללים את הקישור ללוח**: `kiddush/?sheet=<מזהה הגיליון>`.
3. **מתפלל נרשם.** בלוח הוא לוחץ על שבת פנויה ואז "הרשמה לקידוש", וממלא שם תורם, הקדשה (לע"נ / לזכות) ושם, סיבה, טלפון והערה.
   שומר הסף ([apps-script/Code.gs](apps-script/Code.gs)) כותב את הרישום לגיליון רק אם השבת עדיין פנויה. אם שניים נרשמים יחד, הראשון נרשם והשני מקבל הודעה שהשבת תפוסה.
   שינוי או ביטול של רישום נעשים על ידי הגבאי בגיליון.
4. **הלוח מציג את הרישומים**, בלי מספרי הטלפון. הוא קורא את הגיליון דרך שומר הסף בכל פתיחה, בלחיצה על כפתור הרענון, וכשחוזרים אליו אחרי יותר מדקה.
   המידע האחרון נשמר במכשיר, כך שהלוח נפתח גם בלי אינטרנט.
5. **שנה חדשה.** בתפריט ההגדרות של הלוח יש כפתור "הוספת שנה נוספת לגיליון". הוא עובד רק מחשבון הגוגל שיצר את הגיליון.

כדי שהלוח יעבוד, בעל האתר צריך פעם אחת להעלות את שומר הסף ולרשום את האתר בגוגל: [docs/google-setup.md](docs/google-setup.md).

## מבנה הגיליון

לשונית **קידושים**: שורה 1 היא כותרת, שורה 2 הסבר ושורה 3 כותרות העמודות. הנתונים מתחילים בשורה 4.

| עמודה | תוכן |
|---|---|
| A | תאריך לועזי, `dd/mm/yyyy` (טקסט) |
| B | תאריך עברי |
| C | שבת / חג |
| D | שם התורם. שורה עם ערך כאן נחשבת תפוסה, ושומר הסף לא יכתוב עליה |
| E | לע"נ / לזכות (רשימת בחירה) |
| F | שם הנפטר או האדם שהקידוש לזכותו |
| G | סיבה |
| H | טלפון (לא מוצג בלוח) |
| I | הערה |

עמודות A–C ושורות הכותרת מוגנות באזהרה: אפשר לערוך אותן, אבל גוגל מבקשת אישור לפני כן.
הגבאי יכול להוסיף שורות בתאריכים נוספים, והלוח יציג אותן בחודש המתאים.
הגיליון מסומן (Developer Metadata בשם `kiddushBoard`), ושומר הסף עובד רק עם גיליונות שמסומנים כך.

לשונית **הגדרות**: `שם בית הכנסת`, `מיקום` (ארץ ישראל / חוץ לארץ), `קישור ללוח באתר`.

## מבנה התיקייה

| קובץ | תפקיד |
|---|---|
| `index.html` | שלד העמוד |
| `css/styles.css` | עיצוב, ערכי צבע לבהיר וכהה, RTL |
| `js/config.js` | מזהה ההתחברות של האתר בגוגל וכתובת שומר הסף |
| `js/calendar.js` | חישוב שבתות, פרשות וחגים לפי מיקום (א״י / חו״ל). חושף `window.KiddushCalendar` |
| `js/sheets.js` | קריאה והרשמה דרך שומר הסף, יצירת גיליון והוספת שנה. חושף `window.KiddushSheets` |
| `apps-script/Code.gs` | שומר הסף: סקריפט אחד בחשבון של בעל האתר, לכל בתי הכנסת |
| `js/app.js` | המסכים והפעולות |
| `docs/google-setup.md` | רישום האתר בגוגל, פעם אחת |

## תלויות

- `@hebcal/core@6.9.3` מ-`../vendor/hebcal/` (לוח עברי, פרשות, חגים)
- גופנים: Frank Ruhl Libre, Assistant (Google Fonts)
- קריאה והרשמה: שומר הסף (Google Apps Script web app), בלי התחברות של המתפלל
- יצירה: Google Identity Services, Sheets API v4 ו-Drive API v3, עם ההרשאה `drive.file` בלבד

## הרצה מקומית

מתיקיית האתר הראשית: `npm start`, ואז http://localhost:8080/kiddush/
