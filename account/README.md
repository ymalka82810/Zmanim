# החשבון שלי וקהילות

דף משותף לכל חלקי האתר: כניסה עם Google, פתיחת קהילה, הצטרפות וניהול חברים. הנתונים נשמרים ב-Convex (`convex/`).

## תפקידים

| תפקיד | הרשאות |
|---|---|
| גבאי | הזמנת חברים, שינוי תפקידים והסרה, עריכת פרטי הקהילה, ניהול קישור ההזמנה |
| רב | בדיוק כמו גבאי |
| חבר קהילה | צפייה, והצטרפות או עזיבה |

מי שפותח קהילה נרשם בה כגבאי. בכל קהילה חייב להישאר לפחות גבאי או רב אחד. כל בדיקות ההרשאה נעשות בשרת, ב-`convex/roles.ts`.

## הצטרפות לקהילה

- **הזמנה לפי מייל** (`convex/invitations.ts`): גבאי או רב מקליד כתובת Gmail ובוחר תפקיד. כשבעל המייל נכנס לאפליקציה, גם אם לא נרשם קודם, הוא רואה את ההזמנה תחת "הזמנות שממתינות לך" ובוחר "הצטרפות" או "דחייה".
- **קישור הזמנה כללי** (`convex/invites.ts`): `account/?join=<code>`. מי שנכנס דרכו מצטרף כחבר קהילה. רק גבאי ורב רואים את הקישור ויכולים להחליף אותו.

## הקהילה הפעילה

משתמש יכול להשתייך לכמה קהילות. הקהילה הפעילה נשמרת בדפדפן דרך `SiteAuth.activeSynagogueId()` ו-`SiteAuth.setActiveSynagogueId()` שב-`js/auth.js`. לוח הזמנים, לוח הקידושים והקופה יציגו את הנתונים של הקהילה הזו.
