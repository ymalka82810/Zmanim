# לוח קידושים לקהילה

מערכת להרשמה לקידושים בשבתות ובחגים. היא חלק מאתר לוח הזמנים, בכתובת `kiddush/`, ומציגה את הלוח של הקהילה הפעילה (ראו `account/README.md`).

## מבנה התיקייה

| קובץ | תפקיד |
|---|---|
| `index.html` | שלד העמוד, טוען את כל הקבצים |
| `css/styles.css` | עיצוב, ערכי צבע לבהיר וכהה, RTL |
| `js/calendar.js` | חישוב שבתות, פרשות וחגים לפי מיקום (א״י / חו״ל). חושף `window.KiddushCalendar` |
| `js/app.js` | מצב האפליקציה, מסכים ופעולות |
| `docs/data-model.md` | מבנה הנתונים |

צד השרת נמצא ב-`convex/kiddush.ts`, והטבלאות ב-`convex/schema.ts`.

## תלויות

- `@hebcal/core@6.9.3` מ-`../vendor/hebcal/` (לוח עברי, פרשות, חגים)
- Convex: `../vendor/convex/`, `../js/convex-config.js`, `../js/auth.js` (התחברות עם Google והקהילה הפעילה)
- גופנים: Frank Ruhl Libre, Assistant (Google Fonts)

## הרצה מקומית

מתיקיית האתר הראשית: `npm start`, ואז http://localhost:8080/kiddush/

## תפקידים

התפקידים באים מהקהילה ב-Convex. כל ההרשאות נבדקות בשרת.

- **חבר קהילה**: צפייה בלוח, הרשמה, ביטול של רישום שלו בלבד, "הקידושים שלי". הוא לא יכול למחוק או לבטל רישום של משתמש אחר, גם כשהרישום עדיין ממתין לאישור. הטלפון וההערה של נרשמים אחרים לא נשלחים אליו.
- **גבאי ורב**: בנוסף, אישור או דחייה של רישומים, רישום ידני, חסימת תאריכים ועריכת ההנחיות עם היסטוריית גרסאות.

ניהול חברי הקהילה, התפקידים וההזמנות נעשה בדף "החשבון שלי".
