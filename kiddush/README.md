# לוח קידושים לבית כנסת

לוח שבתות וחגים שמציג מי נותן קידוש בכל שבת. הנתונים נמצאים בגיליון גוגל של בית הכנסת:
המתפללים נרשמים בגיליון, והלוח באתר מסדר את הרישומים לפי חודש עברי או לועזי.

המערכת היא חלק מאתר לוח הזמנים, בכתובת `kiddush/`.

## איך זה עובד

1. **הגבאי מקים גיליון.** בעמוד הפתיחה של הלוח הוא ממלא את שם בית הכנסת ואת המיקום ולוחץ "יצירת הגיליון בגוגל".
   הגיליון נוצר בדרייב של הגבאי, עם שורה לכל שבת וחג בשנה הקרובה, והוא משותף לכל מי שיש לו את הקישור.
2. **הגבאי שולח למתפללים את הקישור ללוח**: `kiddush/?sheet=<מזהה הגיליון>`.
3. **מתפלל נרשם.** בלוח הוא לוחץ על שבת פנויה ואז "להרשמה בגיליון". הגיליון נפתח בשורה של אותה שבת,
   והמתפלל ממלא בה שם תורם, לע"נ / לזכות ושם, סיבה, טלפון והערה.
4. **הלוח מציג את הרישומים.** הוא קורא את הגיליון בכל פתיחה, בלחיצה על כפתור הרענון, וכשחוזרים אליו אחרי יותר מדקה.
   המידע האחרון נשמר במכשיר, כך שהלוח נפתח גם בלי אינטרנט.
5. **שנה חדשה.** בתפריט ההגדרות של הלוח יש כפתור "הוספת שנה נוספת לגיליון". הוא עובד רק מחשבון הגוגל שיצר את הגיליון.

כדי שיצירת גיליון תעבוד, בעל האתר צריך לרשום את האתר בגוגל פעם אחת: [docs/google-setup.md](docs/google-setup.md).

## מבנה הגיליון

לשונית **קידושים**: שורה 1 היא כותרת, שורה 2 הסבר ושורה 3 כותרות העמודות. הנתונים מתחילים בשורה 4.

| עמודה | תוכן |
|---|---|
| A | תאריך לועזי, `dd/mm/yyyy` (טקסט) |
| B | תאריך עברי |
| C | שבת / חג |
| D | שם התורם. שורה עם ערך כאן נחשבת תפוסה |
| E | לע"נ / לזכות (רשימת בחירה) |
| F | שם הנפטר או האדם שהקידוש לזכותו |
| G | סיבה |
| H | טלפון |
| I | הערה |

עמודות A–C ושורות הכותרת מוגנות באזהרה: אפשר לערוך אותן, אבל גוגל מבקשת אישור לפני כן.
הגבאי יכול להוסיף שורות בתאריכים נוספים, והלוח יציג אותן בחודש המתאים.

לשונית **הגדרות**: `שם בית הכנסת`, `מיקום` (ארץ ישראל / חוץ לארץ), `קישור ללוח באתר`.

## מבנה התיקייה

| קובץ | תפקיד |
|---|---|
| `index.html` | שלד העמוד |
| `css/styles.css` | עיצוב, ערכי צבע לבהיר וכהה, RTL |
| `js/config.js` | מזהה ההתחברות של האתר בגוגל |
| `js/calendar.js` | חישוב שבתות, פרשות וחגים לפי מיקום (א״י / חו״ל). חושף `window.KiddushCalendar` |
| `js/sheets.js` | קריאת הגיליון, יצירת גיליון והוספת שנה. חושף `window.KiddushSheets` |
| `js/app.js` | המסכים והפעולות |
| `docs/google-setup.md` | רישום האתר בגוגל, פעם אחת |

## תלויות

- `@hebcal/core@6.9.3` מ-`../vendor/hebcal/` (לוח עברי, פרשות, חגים)
- גופנים: Frank Ruhl Libre, Assistant (Google Fonts)
- קריאה: ממשק gviz של Google Sheets (`/gviz/tq?tqx=out:csv`), בלי התחברות
- יצירה: Google Identity Services, Sheets API v4 ו-Drive API v3, עם ההרשאה `drive.file` בלבד

## הרצה מקומית

מתיקיית האתר הראשית: `npm start`, ואז http://localhost:8080/kiddush/
